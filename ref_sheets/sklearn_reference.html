Scikit-learn Quick Reference

Universal Pattern: fit / predict / score

model.fit(X_train, y_train)
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)   # class probabilities (if available)
score = model.score(X_test, y_test)      # default metric (accuracy for classif, R² for reg)

Gradient Boosting

from sklearn.ensemble import GradientBoostingClassifier

model = GradientBoostingClassifier(
    n_estimators=100,       # number of boosting stages
    learning_rate=0.1,      # shrinkage — lower = more trees needed, but better
    max_depth=3,            # depth of each tree (typically 3-8)
    subsample=0.8,          # fraction of samples per tree (stochastic GB)
    random_state=42,
)
model.fit(X_train, y_train)
# model.feature_importances_
# model.train_score_    → training loss at each stage
# model.oob_improvement_ (if subsample < 1)

# Plot training curve (staged predictions)
from sklearn.metrics import log_loss
test_scores = []
for y_pred in model.staged_predict_proba(X_test):
    test_scores.append(log_loss(y_test, y_pred))

Metrics

from sklearn.metrics import (accuracy_score, f1_score, precision_score, recall_score,
                             confusion_matrix, classification_report,
                             mean_squared_error, r2_score)

# Classification
accuracy_score(y_true, y_pred)
f1_score(y_true, y_pred, average='weighted')  # 'binary', 'micro', 'macro', 'weighted'
precision_score(y_true, y_pred, average='weighted')
recall_score(y_true, y_pred, average='weighted')
confusion_matrix(y_true, y_pred)
print(classification_report(y_true, y_pred))   # precision, recall, f1 per class

# Regression
mean_squared_error(y_true, y_pred)
r2_score(y_true, y_pred)

# Probabilistic
from sklearn.metrics import log_loss, roc_auc_score
log_loss(y_true, y_proba)
roc_auc_score(y_true, y_proba[:, 1])  # binary only

When to use which classification metric

Metric What it measures Use when
Accuracy % correct overall Classes are balanced; all errors cost equally
Precision Of predicted positives, how many are correct? False positives are costly (e.g. spam filter — don’t lose real mail)
Recall Of actual positives, how many did we catch? False negatives are costly (e.g. disease screening — don’t miss cases)
F1 Harmonic mean of precision and recall You need a single number balancing both; class imbalance makes accuracy misleading
AUROC Ranking quality across all thresholds (uses probabilities) You care about ranking, not a specific threshold; binary classification
Log loss How well-calibrated are the probabilities? You need reliable probability estimates, not just correct labels

Multiclass average= parameter: - 'binary' — default for 2-class; reports for the positive class only - 'macro' — unweighted mean across classes (treats rare classes equally) - 'weighted' — weighted by class support (accounts for imbalance) - 'micro' — global TP/FP/FN (equivalent to accuracy for multiclass)

Working with Categorical / Mixed-Type Data

The problem

Sklearn models only accept numeric arrays. Categorical features (color, size, country) must be encoded first. The right encoding depends on the model.

Encoding strategies

from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder

# OneHotEncoder — one binary column per category
# Use for: linear models, SVMs, MLPClassifier (anything that interprets magnitude)
enc = OneHotEncoder(sparse_output=False, handle_unknown='ignore')
X_encoded = enc.fit_transform(X[['color', 'size']])
# 'color' with values [red, blue, green] → 3 binary columns

# OrdinalEncoder — maps categories to integers (0, 1, 2, ...)
# Use for: tree-based models only (they just split on thresholds, don't care about ordering)
enc = OrdinalEncoder()
X_encoded = enc.fit_transform(X[['color', 'size']])
# Faster & more compact than one-hot. But wrong for linear models (implies red < blue < green).

ColumnTransformer — different transforms for different columns

from sklearn.compose import ColumnTransformer

cat_cols = ['color', 'size']
num_cols = ['age', 'income']

# For linear models / SVMs / MLP: scale numeric, one-hot categoricals
preprocessor = ColumnTransformer([
    ('num', StandardScaler(), num_cols),
    ('cat', OneHotEncoder(handle_unknown='ignore'), cat_cols),
])

# For tree models: no scaling needed, ordinal encoding is fine
preprocessor_tree = ColumnTransformer([
    ('num', 'passthrough', num_cols),          # trees don't need scaling
    ('cat', OrdinalEncoder(), cat_cols),
])

Full pipelines with categorical data

from sklearn.neural_network import MLPClassifier

# Logistic regression with mixed-type data
pipe_lr = make_pipeline(
    ColumnTransformer([
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore'), cat_cols),
    ]),
    LogisticRegression(max_iter=1000),
)

# MLP with mixed-type data (sklearn MLP has no embeddings — just one-hot encode)
pipe_mlp = make_pipeline(
    ColumnTransformer([
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore'), cat_cols),
    ]),
    MLPClassifier(hidden_layer_sizes=(64, 64), max_iter=500),
)

# Gradient boosting with ordinal encoding (faster, works fine for trees)
pipe_gb = make_pipeline(
    ColumnTransformer([
        ('num', 'passthrough', num_cols),
        ('cat', OrdinalEncoder(), cat_cols),
    ]),
    GradientBoostingClassifier(n_estimators=100),
)

# All use the same API:
pipe_lr.fit(X_train, y_train)
pipe_lr.score(X_test, y_test)

Quick reference: which encoding for which model?

Model Encoding Why
Logistic Regression, SVM OneHot Interprets numeric magnitude — ordinal integers are misleading
MLPClassifier (sklearn) OneHot Same reason — no embedding layer in sklearn’s MLP
Decision Tree, RF, GB Ordinal Trees split on thresholds — integer encoding is fine and more compact
HistGradientBoosting None (native) Pass categorical_features= — handles categories internally
PyTorch MLP nn.Embedding Learns dense representations — see PyTorch sheet

Decision Boundary Visualization (2D)

def plot_decision_boundary(model, X, y, ax=None):
    if ax is None:
        fig, ax = plt.subplots()
    h = 0.02
    x_min, x_max = X[:, 0].min() - 0.5, X[:, 0].max() + 0.5
    y_min, y_max = X[:, 1].min() - 0.5, X[:, 1].max() + 0.5
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                          np.arange(y_min, y_max, h))
    Z = model.predict(np.column_stack([xx.ravel(), yy.ravel()]))
    Z = Z.reshape(xx.shape)
    ax.contourf(xx, yy, Z, alpha=0.3, cmap='RdBu')
    ax.scatter(X[:, 0], X[:, 1], c=y, cmap='RdBu', edgecolors='k', s=20)
